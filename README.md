# Lysander Ricalde Jr. — Personal Portfolio

A responsive personal portfolio built with semantic HTML and CSS.

## Project structure

```text
ricalde-project-1/
├── index.html
├── styles/
│   └── style.css
├── assets/
│   └── README.md
└── README.md
```

## Run locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Before publishing

1. Replace `your-email@example.com` in `index.html` with your active email address.
2. Add your own profile photo or project screenshots to `assets/` if you want to personalize the design further.
3. Update the project cards with your real completed work.

## Publish with GitHub Pages

1. Create a GitHub repository named `ricalde-project-1` (or another name you prefer).
2. In this folder, connect the repository and push the `main` branch:

   ```bash
   git remote add origin https://github.com/YOUR-USERNAME/ricalde-project-1.git
   git push -u origin main
   ```

3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages settings.
